## 🔭 Currently Working On

**Quiver** - Building an AI-powered knowledge management system that transforms how teams capture, organize, and retrieve institutional knowledge. Features include:
- Multi-persona RAG (Retrieval-Augmented Generation) system for context-aware responses
- Intelligent document processing pipeline with vector embeddings
- Real-time knowledge synthesis across multiple data sources
- Production deployment using FastAPI, PostgreSQL, and modern cloud infrastructure

**AI-Driven Program Management** - Exploring how AI agents can augment technical program management through automated status reporting, risk prediction, and intelligent resource optimization.
